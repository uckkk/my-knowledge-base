# Stone Design 统一效果页（公开）

统一交互页，展示设计系统里**已经存在**的令牌、组件、效果与糖胶水果。网页演示不是 Metal / SwiftUI 原生来样运行。

公开地址：https://istone.cc/design/

## 内容

- 效果预览包为准：令牌、组件、效果（软胶 / 漆面 / 注视 / 拉丝）、原生参考、覆盖清单
- 规范补录：转交手册里预览页没有的条文——原则摘要、使用与禁止、网页适配 CSS 变量、约束提示词全文、验收清单
- 糖胶水果全套（v12）：可玩游戏（fruit-goo-playground.html 内嵌）、19 种水果图鉴、实现要点

## 分类（2026-11-16）

- 界面类：令牌、组件
- 动效类：效果、原生参考
- 游戏类：糖胶水果（可玩游戏、图鉴、实现要点）
- 规范类：规范补录、覆盖清单

左栏按类分组，正文每类前有分隔带，说明区顶部有四张分类卡。章节顺序与分类一致。

## 目录

- `index.html` 统一页（中文）
- `css/stone.css` 令牌与组件样式（含统一页新增的图鉴、代码块、游戏框样式）
- `js/effects.js` 软胶 / 漆面 / 注视 / 拉丝的 Canvas SDF
- `js/app.js` 主题、强调色、减弱动态、组件交互、覆盖清单
- `js/coverage-data.js` 覆盖清单内嵌数据（64 项）
- `data/tokens.json` 从源码提取的令牌
- `data/coverage.json` 覆盖清单
- `media/` 颗粒瓦片，以及已有的 kiss-v5 / gaze-v8 / flow-v9 参考录像与静帧
- `fruit-goo-playground.html` 果合大作战可玩游戏（自包含，约 8MB；需点击开始才跑循环，离开视口/标签暂停；物理 60Hz）
- `fruit-goo/` 19 种水果主图（按进化链顺序）
- 统一页内游戏改为按钮按需加载，避免一进设计页就下载 8MB 并占满本机 CPU

## 覆盖

见页内「覆盖清单」，或 `data/coverage.json` 的 `meta.counts`（64 项：Web 等价 54、原生参考 4、不可模拟 6）。

三类：

- **Web 等价**：可在本页交互查看，并标明与原生的差异
- **原生参考**：已有真实录像或静帧，不是本页实时着色器
- **不可模拟**：触觉、Metal 库、陀螺仪姿态、Liquid Glass 等，只列清，需原生验证

## 使用注意

- 浅色 / 深色、八个强调色、减弱动态在顶栏切换
- 软胶与漆面拉丝是连续 SDF 表面，不是粗线假冒胶颈
- 漆面按钮的绳索物理相对原生 4 股 × 15 点有简化
- 圆角是 CSS 近似，不是 SwiftUI `.continuous`
- 糖胶水果方向：Q 弹在水果本身，水果之间不加元素；胶颈、拉丝方向已作废
